🖼️ Karuka Image Editor
A lightweight image editor for Linux built with Python.

✨ Features
·	✂️ Crop images
·	📏 Resize images
·	🔄 Rotate images
·	🔁 Convert formats
·	🎯 Background removal

🚀 Download
👉 Download Latest AppImage

▶️ How to Run
After downloading:
chmod +x Karuka.AppImage
./Karuka.AppImage


📦 AppImage Info
·	Format: AppImage (portable Linux app)
·	No installation required
·	Works on most Linux distributions

karuka_image_editor_basic/

## 🛠️ Build from Source (First Time Setup)

> ⚠️ **For developers / advanced users only**
> This will build the AppImage from scratch.

### 🚀 Steps

```bash
git clone https://github.com/leo22092/karuka_image_editor_v1
cd karuka_image_editor_v1

# First-time setup (creates venv + installs dependencies)
bash -x build_appimage.sh --fresh
```

### 📦 Output

After completion, you will get:

```bash
Karuka.AppImage
```

### ▶️ Run

```bash
chmod +x Karuka.AppImage
./Karuka.AppImage
```
