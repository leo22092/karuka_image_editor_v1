🖼️ Karuka Image Editor
A lightweight image editor for Linux built with Python.

✨ Features
·	✂️ Crop images
·	📏 Resize images
·	🔄 Rotate images
·	🔁 Convert formats
·	🎯 Background removal

🚀 Download
👉 Download Latest AppImage

▶️ How to Run
After downloading:
chmod +x Karuka.AppImage
./Karuka.AppImage


📦 AppImage Info
·	Format: AppImage (portable Linux app)
·	No installation required
·	Works on most Linux distributions

🧰 Project Structure
karuka_image_editor_basic/
├── core/
├── ui/
├── utils/
├── main.py


🛠️ Build (for developers)
git clone https://github.com/leo22092/karuka_image_editor_v1
cd karuka_image_editor_v1
./build_appimage.sh
